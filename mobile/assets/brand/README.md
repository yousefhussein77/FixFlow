# FixFlow brand assets

The canonical source is `source/fixflow_logo_master.svg`. It uses the approved geometric FixFlow direction: an interlocking blue `F`/flow path with a restrained orange forward accent.

Runtime names follow `fixflow_<mark-or-lockup>_<orientation>_<light-or-dark-or-mono>.<ext>`. Use horizontal variants at 120 logical pixels wide or larger and icon variants at 24 logical pixels or larger. Clear space around the mark is at least one orange-node diameter.

## Prohibited usage

Do not stretch, rotate, rearrange, recolor, shadow, outline, crowd, place on a low-contrast background, or combine the mark with another identity. Brand marks never mirror in RTL. Android launcher and splash files are derivatives of this source and require visual approval before release.
